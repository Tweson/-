Руководство пользователя
========================

1. Запустите `main.py` или `main.exe`.
2. Войдите в систему или зарегистрируйтесь.
3. На вкладке «Расчёт печати» выберите клиента, тираж и бумагу.
4. Нажмите «Рассчитать», затем «Сохранить заказ».
5. Для пополнения склада перейдите на вкладку «Склад бумаги».
