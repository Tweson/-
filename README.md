# Типография: Калькулятор заказов

Настольное приложение для автоматизации расчёта стоимости полиграфических заказов, учёта очереди печати и контроля расхода материалов. Разработано в рамках учебной практики УП.01 (специальность 09.02.07).

## 🚀 Основные возможности

*   **Калькулятор заказов:** автоматический расчёт стоимости с учётом тиража, количества страниц и наценки.
*   **Очередь печати:** отслеживание статусов заказов (Новый, В работе, Готов, Выдан) с возможностью фильтрации.
*   **Учёт склада:** автоматическое списание бумаги при выполнении заказа, уведомление о нехватке материалов.
*   **Статистика:** отображение выручки и количества заказов с фильтрацией по датам (сегодня, вчера, за всё время).
*   **Настройки:** возможность смены аватарки профиля и восстановления базы данных из резервной копии.
*   **Безопасность:** авторизация пользователей с хэшированием паролей.

## 🛠 Технологический стек

*   **Язык программирования:** Python 3.10+
*   **Библиотека GUI:** PyQt6
*   **СУБД:** SQLite 3 (встроенный модуль `sqlite3`)
*   **Тестирование:** Pytest
*   **Инструменты:** Black, Flake8, PyInstaller, Sphinx
